# 🌍 Smart Route Finder

> 🚀 A modern full-stack web app that finds the **shortest path between locations** using **Dijkstra’s Algorithm** — with interactive graph visualization and real-world feel.

---

## ✨ Live Experience

🔍 Select locations → ⚡ Calculate route → 📍 Visualize path → 🧠 Understand logic  

---

## 🎯 Key Highlights

- 🧠 **DSA Applied** – Real-world use of Dijkstra Algorithm  
- 📊 **Graph Visualization** – Interactive nodes & edges  
- 🗺️ **Map Integration** – Route displayed visually  
- 🎨 **Modern UI** – Clean, responsive, smooth experience  
- ⚡ **Fast Performance** – Optimized API + frontend  

---

## 🛠️ Tech Stack

**Frontend**
- React.js (Vite)
- Tailwind CSS
- React Flow

**Backend**
- Node.js
- Express.js

---

## ⚙️ How It Works

```text
User Input → Backend (Dijkstra Algorithm) → Shortest Path → UI (Graph + Map)

git clone https://github.com/your-username/smart-route-finder.git

cd smart-route-finder

# Backend
cd server
npm install
npm start

# Frontend
cd ../client
npm install
npm run dev

```
