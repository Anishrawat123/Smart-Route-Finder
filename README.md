# 🚀 Smart Route Finder

A full-stack web application that finds the **shortest path between locations** using **Dijkstra’s Algorithm**, with interactive graph visualization and a clean UI.

---

## 🌟 Features

- 🔍 Shortest path calculation (DSA)
- 📊 Graph visualization (React Flow)
- 🗺️ Map-based UI
- 🎯 Real-world city mapping
- ⚡ Fast, responsive, and user-friendly interface

---

## 🛠️ Tech Stack

- Frontend: React.js (Vite), Tailwind CSS  
- Backend: Node.js, Express.js  
- Algorithm: Dijkstra (Graph-based shortest path)

---

## 🧠 How It Works

User selects start & end → Backend runs Dijkstra → Shortest path calculated → Result shown with distance + path + graph.
